\begin{enumerate}[series=q]
\item Consider the following ``coloring'' algorithm. Initially, all edges are uncolored. Then apply the following rules in arbitrary order until all edges are colored.

\noindent \textbf{Blue rule:} Select a cut containing no blue edge. Among the uncolored edges in the cut, select one of minimum cost and color it blue.

\noindent \textbf{Red rule:} Select a circuit (cycle) containing no red edge. Among the uncolored edges in the circuit, select one of maximum cost and color it red.
\begin{enumerate}
\item Show that as long as there are uncolored edges left, one of the rules is applicable.
\item Show that at all points, there exists a minimum spanning tree containing all blue edges but no red edge, so in the end the algorithm solves the MST problem.
\item Show that Kruskal's and Prim's algorithms are special cases of this algorithm.
\end{enumerate}
\end{enumerate}

\solution
 
\paragraph{(a)}
Suppose there exists an uncolored edge $e=uv$. 
Let $V_u$ and $V_v$ be the vertices reachable from $u$ and $v$, respectively, in the blue subgraph.
If $u$ and $v$ are in the same blue component, there exists a blue path $P$ from $u$ to $v$. 
But $P+e$ forms a cycle with no red edges, which means the red rule can be applied to color $e$ red.
Otherwise, $u$ and $v$ are in different blue components with vertex sets $V_u$ and $V_v$, respectively. 
Thus, the cut $\delta(V_u)$ forms a cut with no blue edges, and thus the blue rule can be applied.
\qed

\paragraph{(b)}
On a (partially) colored graph, let $T$ be an $MST$ which uses all blue edges and possibly some uncolored edges.
We will consider the next edge to be colored $e=uv$.

If $e$ is colored blue and $e\in T$, we are done since $T$ is still an MST in the new graph that uses all blue edges. 
If $e$ is colored blue and $e\notin T$, consider the fundamental cycle $C$ of $e$ and the cut $D$ chosen by the blue rule which would color $e$. 
Any cut and cycle must intersect on an even number of edges, and we know $e\in C\cap D$, so there must exist another edge $e'\in (C - e) \cap D$.
Since $e'$ is not colored blue since $e'\in D$, neither is it colored red since $e'\in T$.
Hence, $e'$ is uncolored.
Since the blue rule chose $e$ instead of $e'$, we get $c(e')\geq c(e)$.
Thus, we have $c(T-e'+e) \leq c(T)$, and $T-e' + e$ forms our desired MST in the new graph as it is a tree containing all blue edges and no red edges.

Otherwise, $e$ is colored red. 
If $e\notin T$, we are done, since $T$ is still in the new graph.
Otherwise, $e\in T$, and let $C$ be the cycle used by the red rule. 
Deleting $e$ from $T$ splits the remaining edges of $T$ into two connected components, and there exists some $e'\in C\setminus T$ which connects these two components.
Since $e'\in C$, by the red rule, $e'$ is not colored red.
If $e'$ were colored blue, then it would already be in $T$, which contradicts $e'\in C\setminus T$.
Thus, $e'$ is uncolored, so by the red rule, $c(e)\geq c(e')$.
Finally, $c(T-e+e')\leq c(T)$, and $T-e+e'$ forms our desired MST in the new graph as it is a tree containing all blue edges and no red edges.

The algorithm colors one edge on every iteration and there are a finite number of edges. Hence, it eventually ends up with a blue MST that solves the MST problem.
\qed

\paragraph{(c)}
Kruskal's works by coloring the edges in increasing order of cost, keeping track of the set of blue edges which will be contained in the MST.
When Kruskal's accepts an edge $uv$, the $uv$ is a cheapest edge on the cut $\delta(V_u)$, where $V_u$ is the connected blue component containing $u$. 
Hence, the set of edges accepted by Kruskal's is colored blue by the blue rule.
When Kruskal's rejects an edge $uv$, it is because both $u$ and $v$ are in the same connected blue component $V_{uv}$, so the red rule applies to color $uv$ red by choosing the fundamental circuit of $uv$ in $V_{uv}$.

Prim's repeatedly applies the blue rule similarly to Kruskal's, always growing the same connected component.
After $n-1$ iterations, it obtains a blue tree which is an MST (by part (b)).


\begin{enumerate}[resume=q]
\item Alice and Bob play the following game alternatively on a given simple connected graph $G$: Alice starts the game. At each of her turns, she deletes an edge of $G$. Following Alice, Bob fixes an edge at each of his turns. A fixed edge can not be deleted. Bob wins if he builds a spanning tree of $G$, otherwise, Alice wins. Show that if $G$ has two edge-disjoint spanning trees, then Bob wins the game (In fact, this is also the necessary condition).
\footnote{Serial exchange on the order of selection gives this.}
\end{enumerate}

\solution
We describe and prove a winning strategy for Bob.
Initialize the two spanning trees as the edge-disjoint trees $T_1$ and $T_2$ and let the set of edges Bob takes as $B\gets \emptyset$.
As the game proceeds we evolve $T_1$, $T_2$ and $B$ such that at the end of each of Bob's turns, we maintain the following invariants:
\begin{enumerate}
    \item $T_1$ and $T_2$ remain spanning trees;
    \item $T_1\cap T_2 = B$.
    \item $T_1\cup T_2$ does not contain deleted edges.
\end{enumerate}
Thus, the game ends when $|B|=n-1$ and $B=T_1=T_2$ is a spanning tree.

At the start of the $i$th round, we consider two cases on the edge $e$ which Alice deletes:

\textbf{Case 1: }$e\in T_1\triangle T_2$. Without loss of generality, suppose $e\in T_1$. 
Let $C$ be the fundamental cycle of $e$ in $T_2$.
Then deleting $e$ from $T_1$ produces two connected components $D_1$ and $D_2$.
The cut $\delta(V(D_1))$ and the cycle $C$ must intersect on at least two edges.
Hence, there must exist some edge $e'\in C$ connecting $D_1$ and $D_2$.
Furthermore, since $e'\notin T_1$, therefore $e'\in T_2\setminus T_1$.
Thus, Bob can select $e'$, so $B\gets B+e'$. 
The invariants are maintained, since $T_1\gets T_1-e+e'$ remains a spanning tree, $T_2$ is unchanged, $T_1\cap T_2=B$ and $T_1\cup T_2$ do not contain deleted edges.

\textbf{Case 2: }$e\notin T_1\cup T_2$. 
Bob can select any unselected edge $e\in T_1$.
Let $C$ be the fundamental cycle of $f$ in $T_2$.
Suppose for contradiction that $C-f$ comprised only selected edges. 
Then $C-f\subseteq B = T_1\cap T_2$ by the second invariant, which means $C\subseteq T_1$, which is a contradiction.
Hence, there exists an unselected $f'\in (C-e) \subseteq T_2$ which can be exchanged with $f$.
The invariants are maintained since $T_1$ is unchanged, $T_2\gets T_2-f'+f$ remains a spanning tree, $T_1\cap T_2=B$ and $T_1\cup T_2$ do not contain deleted edges.

\qed

\begin{enumerate}[resume=q]
\item Given a graph $G$, we start modifying it as follows: In each round, as long as $G$ is cyclic, pick an arbitrary cycle of $G$, e.g. $C$, and remove all the edges of $C$ from $G$. Then, add a new vertex to the graph, e.g. $v_C$, and connect $v_C$ to all the vertices of $C$ (note that the newly added vertex can be on the cycles that we pick in the next rounds). Show that regardless of the choice of cycles, $G$ becomes a forest (collection of trees) after a finite number of rounds.
\end{enumerate}

\solution
(A counting proof)

Note that after the operation, the total number of vertices in the graph increases by $1$, but the number of edges remains the same. 
Hence, if the starting number of edges is $k$, after at most $k$ iterations all vertices have degree at most $1$. 

Furthermore, all vertices after each operation have degree at least 1: we only delete edges from vertices of $C$, but we also add one edge to each such vertex.

Therefore, after $k$ iterations, each vertex has degree exactly 1.
Then there are no remaining cycles, since vertices of a cycle have degree at least two, so the algorithm terminates in a finite number of rounds.

When the algorithm terminates, the graph contains no cycles, so it must be a forest.


\begin{enumerate}[resume=q]
\item The tree graph of a connected graph $G$ is the graph whose vertices are the spanning trees $T_1, T_2, \ldots, T_r$ of $G$, with an edge between $T_i$ and $T_j$ if and only if they have exactly $n-2$ edges in common. Show that the tree graph of any connected graph is connected.
\footnote{Serial exchange works for this too.}
\end{enumerate}

\solution
Write $n:=|V(G)|$ and let $\calT(G)$ denote the tree graph of $G$.
Since $G$ is connected it has a spanning tree, so $\calT(G)$ has at least one vertex, and every spanning tree has exactly $n-1$ edges.

\begin{observation}\label{obs:swap-is-edge}
    Let $T$ be a spanning tree, $e\in T$ and $f\in E(G)\setminus T$ with $T':=T-e+f$ a spanning tree.
    Then $T$ and $T'$ are adjacent in $\calT(G)$.
\end{observation}
\begin{proof}
    Since $f\notin T$ we have $f\neq e$, so $T\cap T' = T-e$, which has exactly $n-2$ edges.
\end{proof}

\begin{lemma}\label{lem:exchange}
    Let $T$ and $T^*$ be distinct spanning trees of $G$.
    Then there exist $e\in T\setminus T^*$ and $f\in T^*\setminus T$ such that $T-e+f$ is a spanning tree and $|(T-e+f)\cap T^*| = |T\cap T^*|+1$.
\end{lemma}
\begin{proof}
    As $|T|=|T^*|=n-1$ and $T\neq T^*$, we may pick $e\in T\setminus T^*$.
    Deleting $e$ splits $T$ into two components; let $S$ be the vertex set of one of them, so that $T\cap\delta(S)=\{e\}$.
    Since $T^*$ is a spanning connected subgraph, $T^*\cap\delta(S)\neq\emptyset$; pick $f\in T^*\cap\delta(S)$.
    Then $f\neq e$ because $e\notin T^*$, and hence $f\notin T$ because $e$ is the only edge of $T$ in $\delta(S)$.
    Now $T-e+f$ has $n-1$ edges and is connected, as $f$ rejoins the two components of $T-e$; hence it is a spanning tree.
    It gains $f\in T^*$ and loses $e\notin T^*$, so its intersection with $T^*$ is one larger.
\end{proof}

\begin{theorem}
    For any two spanning trees $T$ and $T^*$ of $G$ there is a path from $T$ to $T^*$ in $\calT(G)$ of length $(n-1)-|T\cap T^*| \leq n-1$.
    In particular, $\calT(G)$ is connected.
\end{theorem}
\begin{proof}
    Set $T_0:=T$ and apply Lemma~\ref{lem:exchange} repeatedly, obtaining spanning trees $T_0,T_1,T_2,\ldots$ with $|T_i\cap T^*| = |T\cap T^*| + i$; by Observation~\ref{obs:swap-is-edge}, $T_{i-1}T_i$ is an edge of $\calT(G)$.
    Since $|T_i\cap T^*|\leq n-1$, with equality precisely when $T_i=T^*$, the construction must halt, and it halts only at $T_k=T^*$ with $k=(n-1)-|T\cap T^*|$.
    This gives the required path.
\end{proof}
\qed

\begin{enumerate}[resume=q]
\item Recall that an edge cut is the set of all edges going from a subset of nodes $S$ to its complement $V \setminus S$, and denoted $[S, V \setminus S]$. Prove that the symmetric difference of two different edge cuts is an edge cut.
\end{enumerate}

\solution
Let the two cuts be defined by vertex sets $P,Q$. 
This partitions the vertex set into four (possibly empty) groups:
\begin{align*}
    A:= P\cap Q, \quad B:=P\cap \overline{Q}, \quad C:=\overline{P}\cap Q, \quad D:=\overline{P}\cap \overline{Q}.
\end{align*}
Let $E_{XY}$ be the edges between components $X$ and $Y$. We have:
\begin{align*}
    \delta(P) = E_{AC} \cup E_{BD}\cup E_{AD}\cup E_{BC}, \\
    \delta(Q) = E_{AB} \cup E_{CD}\cup E_{AD}\cup E_{BC}. 
\end{align*}
So 
\begin{align*}
    \delta(P) \triangle \delta(Q) = E_{AB} \cup E_{CD} \cup E_{AC} \cup E_{BD} = \delta(A\cup D),
\end{align*}
which is a cut.

\begin{enumerate}[resume=q]
\item Given an $n$-node directed acyclic graph (DAG), show that the nodes can be numbered with distinct integers from $1$ to $n$ such that all arcs go from smaller to higher numbered nodes. This numbering is called a topological ordering of the graph, and is commonly used in computing quantities on the nodes via dynamic programming.
\end{enumerate}

\solution

\begin{lemma}
    For any vertex $u$ in a DAG $G$, let $R_u\subseteq V$ be the set of vertices reachable from $u$. 
    Then (i) all vertices of $V\setminus R_u$ are not reachable in $G$ from any vertex of $R_u$; (ii) $u$ is not reachable from any vertex in $R_u - u$; and (iii) $G\setminus R_u$ is also a DAG.
\end{lemma}
\begin{proof}
    (i): Clearly, otherwise that vertex would also be in $R_u$.
    
    (ii): Any $v\in R_u$ is reachable from $u$, so if there exists a $(v,u)$-path, then there exists a cycle in $G$.

    (iii): Any cycle in $G\setminus R_u$ is also a cycle in $G$.
\end{proof}

Our algorithm proceeds inductively on the size of $G$.
If $|V|=1$, the topological ordering is just one vertex.
Otherwise, select any $u\in V$ and define $A = V\setminus R_u$ and $B = R_u - u$. 

\begin{lemma}
    There exists a valid topological ordering beginning with the vertices of $A$ in some order, then $u$, then the vertices of $B$ in some order.
\end{lemma}
\begin{proof}
    By the inductive hypothesis, there is a valid topological ordering of the vertices of $A$ and $B$.
    Our ordering will be that of $A$, then $u$, then that of $B$.
    Call an edge \emph{reverse-order} if it is directed from vertex later in the ordering to a vertex earlier in the ordering.

    We show that there are no edges of $G$ crossing the partition $A\sqcup \{u\} \sqcup B$ in the reverse order. 
    There are no reverse-order edges within $A$ or $B$ because they are alredy topologically ordered.
    There is no reverse-order edge $(x,y)$ ending in $A$ because then $y$ should be in $R_u$.
    There is no reverse-order edge from $B$ to $u$ because that would be a cycle in $G$.
\end{proof}

Thus, our algorithm can recursively topologically order $A$ and $B$, giving a topological ordering of $G$.


\begin{enumerate}[resume=q]
\item[7.*] An edge $e$ is a cut edge if $G - e$ has one more connected component than $G$ (in undirected graphs). Show that
\begin{enumerate}
\item if each vertex degree in $G$ is even, then $G$ has no cut edge.
\item if $G$ is a $k$-regular bipartite graph with $k \geq 2$, then $G$ has no cut edge.
\end{enumerate}
\end{enumerate}

\solution
\paragraph{(a)}
\begin{claim}
    Any connected component has an even total degree.
\end{claim}
\begin{proof}
    The sum of all degrees is equal to twice the number of edges.
\end{proof}
Suppose for contradiction that there exists a cut edge $e$, which separates component $C$ into $C_1$ and $C_2$.
Deleting $e$ decreases the total degree of $V(C_1)$ by $1$. Since all vertices were originally of even degree, this means $C_1$ has odd total degree, a contradiction.

\paragraph{(b)}
Suppose for contradiction that there is a cut edge $e= uv$. 
Restrict our attention to the connected component $C$ of $e$ in $G$.
Furthermore, let $C_u$ be the connected component of $G-e$ containing $u$, and let $C_v$ be the connected component of $G-e$ containing $v$.
Then all vertices of $C_u$ are of degree $k$ except for $u$, which is of degree $k-1$.

Let the bipartition of $V(C_u)$ be $A\sqcup B$, and without loss of generality let $u\in A$.
Let $a:=|A|$ and $b:=|B|$. 
Then by counting the degrees of each side,
\begin{align*}
    &(a-1)k + k-1 = bk \\
    &\Rightarrow (a-b)k = 1.
\end{align*}
But $a,b$ are integer and $k\geq 2$, which is a contradiction.

\begin{enumerate}[resume=q]
\item[8.*] Let $G$ be a strongly connected graph with $2n-1$ (directed) edges, i.e., for any ordered pair of vertices $u, v$, there is a directed path from $u$ to $v$. Prove that there exist an edge $e$ in $G$ such that $G - e$ is still strongly connected.
\end{enumerate}

\solution
Select any vertex $r\in G$. 
Since $G$ is strongly connected, there exists an $r$-arborescence $B$ rooted at $r$.
The arborescence $B$ has $n-1$ arcs, so there are $n$ arcs of $G$ remaining.
Since $G$ is strongly connected, each vertex $u\neq r$ has some path to $r$.

If $r$ has an arc outside of $B$, removing it preserves strong connectivity, since $r$ can still reach all other vertices using arcs in $B$ and any other vertex would not use that arc on its shortest path to $r$.
Otherwise, no arcs outside $B$ start at $r$.

For each vertex $u\neq r$, mark one arc starting at $u$ which is on a shortest path from $u$ to $r$. 
If there are multiple such arcs for one $u$, mark any of them. 
Let the set of marked arcs be $C$.

\begin{lemma}
    The graph with arcs $B\cup C$ is strongly connected.
\end{lemma}
\begin{proof}
    Since we have all arcs of $B$, $r$ can reach all other vertices. 
    Every other vertex can reach $r$ by following the arcs of $C$: for vertex $u\neq r$ with arc $uv\in C$, $v$ is one arc closer to $C$ than $u$.
    Hence, all vertices can reach any other vertex by first going through $r$. 
\end{proof}

There are $n-1$ marked arcs in $C$, since there are $n-1$ vertices in $V-r$. 
Hence, $|B\cup C| \leq |B| + |C| = 2n-2$. 
Therefore, there is at least one arc of $G$ that can be removed while preserving strong connectivity.

\begin{enumerate}[resume=q]

    x(E(S)) &\leq |S| - 1 && \forall S \subset V \\

For each $S\subseteq V$, we have the dual variable $y_s$.
Assume the primal problem has a non-negative, integral cost vector $c$.
The dual is as follows:

\begin{align*}
    \max \ (|V|-1)y_V +\sum_{S\subseteq V} (|S|-1)y_S\\
    y_V + \sum_{S\subset V:e\in E(S)} y_S\leq c_e && \forall e\in E \\
    y_S\leq 0 && \forall S\subset V 
\end{align*}

Consider Kruskal's algorithm on the given graph. 
Let the sequence of edges it selects be $E^\ALG = \langle e_1, .. , e_{n-1}\rangle$.
This produces a sequence of forests $F_i:=\bigcup_{j=1}^i \{e_j\}$ for $i\in \{0 .. n-1\}$, where $F_0=\emptyset$ and $F_{n-1}$ is a minimum spanning tree.
For each $i \in \{0.. n-2\}$, let $C_i$ be the connected-component containing $e_i$ in $F_i$, and let $e'_i$ be next edge added to $C_i$.
Let the collection of these components and the final tree $F_{n-1}$ be $\calC$.

Consider the solution $y$ such that 

\begin{align*}
    y_S = \begin{cases}
        c_{e_{n-1}} & \text{for } S=V, \\
        -(c_{e'_i} - c_{e_i})  & \text{for } S = V(C_i), \\
        0 & \text{otherwise.}
    \end{cases}
\end{align*}

\begin{lemma}
    $y$ is dual-feasible.
\end{lemma}
\begin{proof}
    Since Kruskal's adds each $e'_i$ at a later time than $e_i$ we have that $c_{e'_i}\geq c_{e_i}$, so all non-positivity constraints are satisfied.
    For each $e\in E$, consider the following cases
    \begin{enumerate}
        \item \ul{$e \in E^\ALG$.} 
        The only non-zero dual variables in the corresponding constraints are the elements of $\calC$ containing $e$.
        Let $E'':=\langle e''_0=e, .. , e''_k = e_{n-1}\rangle$ be the sequence of edges starting at $e$ such that $e''_{j+1} = e'_j$, i.e., $e''_{j+1}$ is the next edge added to the first component containing $e_j$.
        Note that this sequence must end in $e_{n-1}$, since $e_{n-1}$ is the last edge added and there is only one component in the final spanning tree.
        Hence, we get
        \begin{align*}
            y_V + \sum_{S\subset V:e\in E(S)} y_S & =\sum_{C\in \calC: e\in C} y_{V(C)} \\
            & = c_{e_{n-1}} + \sum_{j=0}^{k-1} \left(- c_{e''_{j+1}} + c_{e''_j}\right) \\
            & = c_{e_{n-1}} - c_{e_{n-1}} + c_{e}&&(\text{telescoping}) \\
            & = c_e. 
        \end{align*}
        Thus, the corresponding constraint holds.
        \item \ul{$e \notin E^\ALG$.} Let $C_i$ be the first component that contains $e$, such that $e_i$ is the corresponding edge in $E^\ALG$ that created that component.
        It follows that the terms on the left-hand-side of the constraint corresponding to $e$ are the same as those of $e_i$'s, since $e$ and $e_i$ share the same first component.
        
        Additionally, $e_i$ and $e$ sharing the first component means that at the time when $e_i$ was first picked, $e$ was not spanned by any existing component.
        According to Kruskal's this means that $c_e\geq c_{e_i}$. Hence, the constraint corresponding to $e$ also holds.
    \end{enumerate}
\end{proof}

Next, we show that the dual objective value attained by $y$ is equal to the primal objective value attained by Kruskal's. 
Together with the fact that all $y_S$ values are integer if all $c_e$ are integer non-negative, This shows that the primal optimal value is also integer, completing the proof.

\begin{lemma}
    The dual objective value attained by $y$ is equal to the primal objective value attained by Kruskal's.
\end{lemma}
\begin{proof}
    (Sketch): Since each component is a tree, the coefficient exactly splits $y_S$ of value into each edge of the final tree it contains.
    Then, we can redistribute the objective such that each edge taken by Kruskal's gets exactly $c_e$ of value.
\end{proof}

\medskip\noindent\textbf{Solution (revised).}\par\medskip

For each $S\subseteq V$, we have the dual variable $y_S$; here $n:=|V|$ and $S$ ranges over the
\emph{nonempty} proper subsets of $V$ (for $S=\emptyset$ the primal constraint reads $0\leq -1$).
Assume the primal problem has a non-negative, integral cost vector $c$.
The dual is as follows, with $y_V$ free because the constraint for $V$ is an equality:

\begin{align*}
    \max \ (|V|-1)y_V +\sum_{S\subset V} (|S|-1)y_S\\
    y_V + \sum_{S\subset V:e\in E(S)} y_S\leq c_e && \forall e\in E \\
    y_S\leq 0 && \forall S\subset V 
\end{align*}

Consider Kruskal's algorithm on the given graph. 
Let the sequence of edges it selects be $E^\ALG = \langle e_1, .. , e_{n-1}\rangle$, so that $c_{e_1}\leq .. \leq c_{e_{n-1}}$.
This produces a sequence of forests $F_i:=\bigcup_{j=1}^i \{e_j\}$ for $i\in \{0 .. n-1\}$, where $F_0=\emptyset$ and $T:=F_{n-1}$ is a minimum spanning tree.
For each $i \in \{1.. n-1\}$, let $C_i$ be the connected-component containing $e_i$ in $F_i$, write $S_i:=V(C_i)$, and for $i\leq n-2$ let $e'_i=e_{\iota(i)}$ be the next edge added to $C_i$, i.e.\ $\iota(i):=\min\{j>i: e_j \text{ has an endpoint in } S_i\}$.
Let the collection of these components and the final tree $F_{n-1}$ be $\calC = \{S_1, .. ,S_{n-1}\}$, where $S_{n-1}=V$ since $T$ is spanning and connected.

\begin{observation}\label{obs:q9}
    \begin{enumerate}
        \item $C_i$ is a tree and $E(T)\cap E(S_i)=E(C_i)$; in particular $|S_i|-1=|E(T)\cap E(S_i)|$.
        \item The $S_i$ are pairwise distinct and $S_i\neq V$ for $i\leq n-2$ (so $e'_i$ exists and $y$ below is well defined), and $\calC$ is laminar.
        \item For $e\in E$ put $\iota(e):=\min\{i: e\in E(S_i)\}$. Then $\{S\in \calC: e\in E(S)\}$ is the chain $S_{i_0}\subsetneq .. \subsetneq S_{i_k}=V$ given by $i_0=\iota(e)$ and $i_{j+1}=\iota(i_j)$.
        \item Every component of $F_{i}$ with at least one edge equals $C_j$ for some $j\leq i$.
    \end{enumerate}
\end{observation}
\begin{proof}
    (1) $C_i$ is a component of a forest, hence a tree on $S_i$; and no $e_j$ with $j>i$ has both endpoints in $S_i$, since $C_i\subseteq F_{j-1}$ is connected and $e_j$ would then close a cycle.

    (2) For $i<j$ both endpoints of $e_j$ lie in $S_j$ but, by (1), not in $S_i$; hence $S_i\neq S_j$.
    By (1), $|S_i|=|E(C_i)|+1\leq i+1<|V|$ for $i\leq n-2$, and as $T$ is connected some later edge then leaves $S_i$, so $\iota(i)$ is well defined.
    Laminarity: $S_i$ is connected in $F_i\subseteq F_j$, hence lies inside a single component of $F_j$, which either is $S_j$ or is disjoint from it.

    (3) First, for $i\leq n-2$, we show that the set $S_{\iota(i)}$ is the smallest member of $\calC$ properly containing $S_i$.
    It contains $S_i$ together with the far endpoint of $e'_i$. 
    For any other member of $\calC$ containing $S_i$, i.e., $S_j \in \calC$ such that $S_j\supsetneq S_i$, by definition of $\iota(i)$, we have that $j>\iota(i)$.
    By the laminarity of $\calC$, $S_j$ must also contain $S_{\iota(i)}$ and is therefore larger than $S_{\iota(i)}$.
    
    Second, $\{S\in\calC : e\in E(S)\}=\{S\in\calC: S\supseteq S_{\iota(e)}\}$: any $S_j$ containing $e$ meets $S_{\iota(e)}$, so by laminarity it contains or is contained in $S_{\iota(e)}$, and in the latter case the paragraph above gives $j<\iota(e)$, contradicting the minimality of $\iota(e)$ unless the two are equal; the converse inclusion is immediate.
    Iterating the first part gives the stated chain, which ends at $S_{n-1}=V$.

    (4) Let $K$ be such a component and $e_j$ its last-added edge, so $j\leq i$ and no edge of $F_i\setminus F_j$ touches $K$; then $K$ is the component of $F_j$ containing $e_j$, i.e.\ $K=C_j$.
\end{proof}

Consider the solution $y$ such that 

\begin{align*}
    y_S = \begin{cases}
        c_{e_{n-1}} & \text{for } S=V, \\
        -(c_{e'_i} - c_{e_i})  & \text{for } S = S_i,\ i\leq n-2, \\
        0 & \text{otherwise.}
    \end{cases}
\end{align*}

\begin{lemma}\label{lem:q9feas}
    $y$ is dual-feasible, and the constraint of every $e\in E^\ALG$ is tight.
\end{lemma}
\begin{proof}
    Since Kruskal's adds each $e'_i$ at a later time than $e_i$ we have that $c_{e'_i}\geq c_{e_i}$, so all non-positivity constraints are satisfied.
    For each $e\in E$, consider the following cases
    \begin{enumerate}
        \item \ul{$e \in E^\ALG$.} 
        The only non-zero dual variables in the corresponding constraint are those indexed by the elements of $\calC$ containing $e$, and by Observation~\ref{obs:q9}(3) these form the chain $S_{i_0}\subsetneq .. \subsetneq S_{i_k}=V$ with $i_0=\iota(e)$.
        Writing $e''_j:=e_{i_j}$, this gives the sequence of edges $E'':=\langle e''_0, .. , e''_k = e_{n-1}\rangle$ with $e''_{j+1} = e'_{i_j}$, i.e., $e''_{j+1}$ is the next edge added to the component $S_{i_j}$.
        Note that this sequence must end in $e_{n-1}$, since $e_{n-1}$ is the last edge added and there is only one component in the final spanning tree.
        Moreover $e''_0=e$: both endpoints of $e=e_m$ lie in $S_m$, and for $j<m$ they cannot both lie in $S_j$ by Observation~\ref{obs:q9}(1), so $\iota(e)=m$.
        Hence, we get
        \begin{align*}
            y_V + \sum_{S\subset V:e\in E(S)} y_S & =\sum_{j=0}^{k} y_{S_{i_j}} \\
            & = c_{e_{n-1}} + \sum_{j=0}^{k-1} \left(- c_{e''_{j+1}} + c_{e''_j}\right) \\
            & = c_{e_{n-1}} - c_{e_{n-1}} + c_{e}&&(\text{telescoping}) \\
            & = c_e. 
        \end{align*}
        Thus, the corresponding constraint holds with equality.
        \item \ul{$e \notin E^\ALG$.} Let $C_i$ be the first component that contains $e$, i.e.\ $i=\iota(e)$, such that $e_i$ is the corresponding edge in $E^\ALG$ that created that component.
        It follows that the terms on the left-hand-side of the constraint corresponding to $e$ are the same as those of $e_i$'s, since by Observation~\ref{obs:q9}(3) both families are $\{S\in\calC: S\supseteq S_i\}$; by case 1 they sum to $c_{e_i}$.
        
        Additionally, $e_i$ and $e$ sharing the first component means that at the time when $e_i$ was first picked, $e$ was not spanned by any existing component: by minimality of $i$ the endpoints of $e$ do not both lie in any $S_j$ with $j<i$, and by Observation~\ref{obs:q9}(4) every component of $F_{i-1}$ with an edge is such an $S_j$ (a component without edges is a single vertex).
        So $e$ was available when Kruskal's chose the cheapest such edge $e_i$, which means $c_e\geq c_{e_i}$. Hence, the constraint corresponding to $e$ also holds.
    \end{enumerate}
\end{proof}

The incidence vector $x^T$ of $T$ is primal-feasible: $x^T\geq 0$, $x^T(E(V))=n-1$, and for each $S$ the edges of $T$ inside $S$ form a forest on $S$, so $x^T(E(S))\leq |S|-1$.
Next, we show that the dual objective value attained by $y$ is equal to the primal objective value attained by Kruskal's.
By weak duality this proves that $x^T$ is an optimal primal solution; since $x^T\in\{0,1\}^E$, the LP attains its optimum at an integral point, and its value $\sum_{e\in E^\ALG}c_e$ is an integer whenever $c$ is, completing the proof.

\begin{lemma}
    The dual objective value attained by $y$ is equal to the primal objective value attained by Kruskal's.
\end{lemma}
\begin{proof}
    Since each component is a tree, Observation~\ref{obs:q9}(1) says that the coefficient $|S_i|-1$ of $y_{S_i}$ counts exactly the edges of the final tree inside $S_i$ (for $S_{n-1}=V$ this count is $|V|-1=|E(T)|$).
    All other coordinates of $y$ vanish, so redistributing the objective over those edges, i.e.\ exchanging the order of summation, gives
    \begin{align*}
        (|V|-1)y_V + \sum_{S\subset V} (|S|-1)y_S 
        & = \sum_{i=1}^{n-1} \left|E(T)\cap E(S_i)\right| y_{S_i} \\
        & = \sum_{e\in E^\ALG} \ \sum_{S\in \calC : e\in E(S)} y_S \\
        & = \sum_{e\in E^\ALG} \left( y_V + \sum_{S\subset V:e\in E(S)} y_S \right) \\
        & = \sum_{e\in E^\ALG} c_e && (\text{Lemma~\ref{lem:q9feas}}) \\
        & = c^\top x^T,
    \end{align*}
    where the third equality uses that $V\in\calC$ contains every edge and that $y_S=0$ for $S\notin \calC$.
    So each edge taken by Kruskal's gets exactly $c_e$ of value.
\end{proof}






\begin{enumerate}[resume=q]
\item[10.**] Given a complete graph on nodes $V$ with a cost $c_{uv}$ between every pair of nodes $\{u,v\}$, partition $V$ into two parts $V_1, V_2$ such that the minimum cost of any edge between nodes in the same part is maximized. In other words, we want to maximize
\[
\min\left\{ \min_{u,v \in V_1} c_{uv}, \min_{u,v \in V_2} c_{uv} \right\}.
\]
Give an efficient algorithm for the task. Show an easy $O(|V|)$ procedure to check whether the solution is unique.
\end{enumerate}

\solution

Assume $|V|\geq 3$, otherwise both parts are singletons and the objective is $\min\emptyset=+\infty$.
For a threshold $t$ write $G_{<t}:=(V,\{\{u,v\}: c_{uv}<t\})$, and likewise $G_{\leq t}$.

\paragraph{Algorithm.}
Starting from the empty graph on $V$, add the edges in ascending order of cost, all edges of one cost at a time.
After each batch, check whether the current graph contains an odd cycle by 2-colouring it with BFS.
Let $t^*$ be the cost of the first batch that creates an odd cycle, and return the 2-colouring $(V_1,V_2)$ of the graph held just before that batch, which is $G_{<t^*}$ (vertices of a component not forced by any edge are coloured arbitrarily).
Some batch does create an odd cycle, since the complete graph on $|V|\geq3$ nodes contains a triangle.

\paragraph{Runtime.}
Sorting costs $O(|V|^2\log|V|)$, and each of the at most $\binom{|V|}{2}$ iterations runs a BFS on $O(|V|^2)$ edges, for $O(|V|^4)$ in total.

\paragraph{Correctness.}
The monochromatic edges of a bipartition are exactly the uncut ones, so for every $t$:
\begin{observation}\label{obs:q10}
    A bipartition $(V_1,V_2)$ has objective value $\geq t$ if and only if it cuts every edge of cost $<t$, i.e.\ if and only if it is a proper 2-colouring of $G_{<t}$.
\end{observation}
\noindent
The graph $G_{<t^*}$ is bipartite, so the returned $(V_1,V_2)$ is a proper 2-colouring of it and by Observation~\ref{obs:q10} has value $\geq t^*$.
Conversely, $G_{\leq t^*}$ contains an odd cycle $C$; no bipartition 2-colours $C$ properly, so every bipartition leaves some edge of $C$ monochromatic, and that edge has cost $\leq t^*$.
Hence $\OPT=t^*$ and the returned bipartition is optimal.

\paragraph{Unique solution.}
Applying Observation~\ref{obs:q10} with $t=t^*=\OPT$: the optimal bipartitions are exactly the proper 2-colourings of $H:=G_{<t^*}$.
Let $k$ be the number of connected components of $H$ and fix the returned colouring $\chi$.
Flipping the colours on any union of components of $H$ again gives a proper 2-colouring, and conversely any proper 2-colouring $\chi'$ agrees with $\chi$ either everywhere or nowhere on each component, since the colour of one vertex of a component determines the colours of the rest.
So the proper 2-colourings are indexed by the $2^k$ subsets of components that are flipped, and two subsets give the same unordered partition exactly when they are complementary; there are $2^{k-1}$ optimal bipartitions.
The solution is therefore unique iff $k=1$, i.e.\ iff $H$ is connected.
The BFS that produced $\chi$ also labels every vertex with its component, so it suffices to scan the $|V|$ labels and check that they are all equal, which takes $O(|V|)$ time.
